# NLP Service

Python FastAPI microservice for resume parsing, semantic matching, and category classification.

## Setup

```bash
cd nlp-service
pip install -r requirements.txt --break-system-packages
python -m spacy download en_core_web_sm
```

**GPU support (recommended for training, optional for inference):**

```bash
# NVIDIA GPU (CUDA)
pip install torch --index-url https://download.pytorch.org/whl/cu121 --break-system-packages

# Apple Silicon / CPU-only machines — standard install already covers this
```

## Classifier: Fine-tuned BERT (self-trained)

The resume category classifier is a `bert-base-uncased` model fine-tuned by our team on the **ResumeAtlas** dataset (13,389 resumes, 43 categories). It is not committed to the repo (model file is ~440MB) — generate it locally once.

### Step 1 — Download the training dataset

```bash
python download_dataset.py
```

Downloads `ahmedheakl/resume-atlas` from Hugging Face into `data/ResumeAtlas.csv`.

### Step 2 — Fine-tune BERT

```bash
python train_bert.py
```

Auto-detects CUDA → Apple MPS → CPU. Saves `./bert_resume_model/` and `bert_label_encoder.pkl`.

**Training time:** GPU ~20-40 min · Apple MPS ~1-2 hrs · CPU not recommended.

**Reference results (3 epochs, RTX 3050):** Accuracy 88.39% · F1 88.28% — replaces earlier TF-IDF + LinearSVC baseline (73.02%, 24 categories).

### Step 3 — Verify labels (optional)

```bash
python get_labels.py
```

## Career Tips (Local LLM via Ollama)

Career recommendations on the job seeker Profile page are generated by a **locally-run open-source LLM** — no external API, no cost, no data leaves your machine.

### Setup

1. **Install Ollama:** https://ollama.com/download (Windows/Mac/Linux)

2. **Pull the model:**

```bash
   ollama pull llama3.2:3b
```

~2GB download. Ollama runs automatically in the background after install (check system tray/menu bar).

3. **Verify Ollama is running:**

```bash
   curl http://localhost:11434
```

Should return `Ollama is running`.

4. **Verify the model responds:**

```bash
   curl http://localhost:11434/api/generate -d "{\"model\": \"llama3.2:3b\", \"prompt\": \"Say hello\", \"stream\": false}"
```

Should return JSON with a `"response"` field.

### How it works

- Tips are generated **once**, when a job seeker uploads their CV — not on every profile visit
- The LLM reads the candidate's full extracted CV text + predicted category + current top job matches
- Output is cached in `cvs.career_tips` (JSONB column) and served instantly on subsequent Profile visits
- Re-uploading a CV regenerates the tips
- If Ollama is not running, tip generation fails gracefully with a fallback message — the rest of the app is unaffected

### If you don't want to run the LLM locally

Career tips will simply show "Recommendations will appear after your next CV upload" — every other feature works normally without Ollama running. It's optional for local development, but should be running before you demo the Profile page.

## Run

```bash
python -m uvicorn main:app --reload --port 8000
```

Verify: http://localhost:8000/health

Startup logs confirm:

- Which device (CUDA/MPS/CPU) BERT is running on
- Whether all models loaded successfully

## Endpoints

| Method | Endpoint         | Purpose                                                                   |
| ------ | ---------------- | ------------------------------------------------------------------------- |
| GET    | /health          | Health check                                                              |
| POST   | /api/parse/cv    | Parse uploaded CV, extract skills + predicted category                    |
| POST   | /api/parse/job   | Parse job description, extract required skills                            |
| POST   | /api/match       | Compute match score between one CV and one job                            |
| POST   | /api/match/batch | Rank multiple CVs against one job description (Batch Ranking tool)        |
| POST   | /api/career-tips | Generate LLM career tips from CV text + category (called once, at upload) |

## Matching methodology

- **Category classification** — fine-tuned BERT (see above)
- **Semantic similarity** — Sentence Transformers (`all-MiniLM-L6-v2`), per CV section vs. job description
- **Section weighting is category-aware** — technical categories (IT, Data Science, DevOps, Developer roles, etc.) weight Projects highest; professional categories (Teacher, Advocate, Agriculture, etc.) weight Experience highest. See `TECHNICAL_CATEGORIES` and `get_section_weights()` in `main.py`
- **Skill matching** — word-boundary regex extraction, alias normalization (e.g. "Golang" = "Go"), and implication mapping (e.g. React implies HTML/CSS/JS) — see `SKILL_ALIASES` and `SKILL_IMPLICATIONS` in `main.py`
- **Composite score** = `(section_score × 0.40) + (skill_overlap × 0.60)`
- **Eligibility threshold** is configurable per organisation (default 65%)

## Known limitations
- Skills lexicon is a fixed list; skills outside it aren't extracted
- Section detection relies on header keywords; unconventional CV formats fall back to full-text similarity
- BERT classifier trained on ResumeAtlas (global, English resumes) — not Nepal-specific
- LLM career tips depend on Ollama running locally; not yet integrated into cloud deployment (see root README deployment notes)
